================================================
  Flow  -  여러 PC에서 같은 내용 쓰기
================================================

집 PC와 회사 PC에서 같은 목록을 쓰는 방법입니다.
안 하셔도 됩니다. 그냥 두면 이 PC 안에서만 돌아갑니다.

준비물은 구글 드라이브(또는 OneDrive) 하나뿐입니다.
Flow 에 가입하거나 로그인할 것은 없습니다.


------------------------------------------------
설정 방법
------------------------------------------------

[ 첫 번째 PC — 지금 쓰던 PC ]

  1. 백업 먼저
     [ ... ] -> 백업 -> [ 지금 백업 ]

  2. G: -> 내 드라이브 안에 폴더 만들기
     이름은 Flow 정도면 됩니다

  3. [ ... ] -> 맨 아래 [ 폴더 바꾸기 ]
     -> 방금 만든 폴더 선택

  4. 앱이 저절로 꺼졌다 켜집니다. 정상입니다.
     설정 맨 아래에 그 폴더 경로가 보이면 성공.


[ 두 번째 PC ]

  1. 구글 드라이브를 같은 계정으로 로그인
     잠시 뒤 그 폴더가 저절로 나타납니다

  2. [ ... ] -> [ 폴더 바꾸기 ] -> 같은 폴더 선택

  끝입니다. 첫 번째 PC 내용이 그대로 넘어옵니다.


------------------------------------------------
주의사항
------------------------------------------------

  - 두 번째 PC 에 원래 적어둔 것은 넘어오지 않습니다.
    첫 번째 PC 내용이 쓰입니다.
    (덮어쓰기 전 백업은 자동으로 남습니다)

  - 구글 드라이브가 꺼져 있으면 Flow 는
    아무것도 저장하지 않고 기다립니다.
    화면에 노란 띠가 뜨는데, 그동안 적은 것은
    저장되지 않으니 띠가 사라진 뒤에 적으세요.

  - 두 PC 를 동시에 켜놓고 양쪽에서 고치지 마세요.
    나중에 저장한 쪽만 남습니다.
    한쪽씩 쓰시면 문제 없습니다.

  - 다른 PC 에서 고친 내용은 1분 안에,
    창을 다시 보면 바로 반영됩니다.

  - 창 위치와 크기, 부팅 시 자동 시작,
    알림이 울렸다는 표시는 따라가지 않습니다.
    PC 마다 화면이 다르고, 알림은 양쪽에서
    다 울려야 하기 때문입니다.

  - 그만두려면 [ 폴더 바꾸기 ] 에서
    다른 폴더를 고르면 됩니다.
    클라우드에 있던 내용은 지워지지 않습니다.
