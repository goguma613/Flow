================================================
  Flow  -  하루 루틴 & 할 일 위젯
================================================

화면 한쪽에 띄워두고 쓰는 작은 할 일 목록입니다.
매일 반복하는 일을 적어두면, 하루가 지날 때
체크가 자동으로 풀리고 날짜도 알아서 바뀝니다.


------------------------------------------------
1. 실행하기
------------------------------------------------

Flow.exe 를 더블클릭하면 바로 실행됩니다.
따로 설치할 것도, 미리 깔아야 할 프로그램도 없습니다.

처음 켜면 사용법이 자동으로 뜹니다.
나중에 다시 보려면 오른쪽 위 ? 버튼을 누르세요.

[ 파란 경고창이 뜨는 경우 ]

  "Windows의 PC 보호" 라는 파란 창이 뜰 수 있습니다.
  개인이 만든 프로그램이라 마이크로소프트에
  등록되어 있지 않아서 나오는 안내입니다.

      "추가 정보" 클릭  ->  "실행" 클릭

  한 번만 해주면 다음부터는 안 뜹니다.

[ 파일 전송이 막히는 경우 ]

  카카오톡이나 메일이 exe 파일을 막는 경우가
  있습니다. 압축(zip)해서 보내면 됩니다.

[ 필요 환경 ]

  Windows 10 또는 11, 64비트


------------------------------------------------
2. 기본 조작
------------------------------------------------

  항목 완료       줄을 아무 데나 클릭
                  (작은 동그라미를 정확히 안 눌러도 됩니다)

  항목 삭제       줄에 마우스를 올리면 오른쪽에
                  휴지통 아이콘이 나타납니다

  이름 바꾸기     항목 위에서 마우스 오른쪽 클릭
                  -> "이름 바꾸기"

  우선순위 변경   할 일 위에서 마우스 오른쪽 클릭

  창 크기 조절    오른쪽 아래 모서리를 끌기
                  두 번 클릭하면 내용에 맞는 높이로

                  작게 줄이면 위쪽 요일과 막대가 접히고
                  할 일 목록이 그 자리를 차지합니다

  창 옮기기       맨 위 날짜 부분을 잡고 끌기
                  (옮긴 위치는 바로 저장됩니다)

  창 숨기기       오른쪽 위  -  버튼
                  시계 옆 트레이로 들어갑니다

  다시 꺼내기     트레이 아이콘 클릭
                  또는  Ctrl + Alt + Space
                  (조합은 설정 · 앱에서 바꿀 수 있습니다)

  완전 종료       오른쪽 위  X  버튼

  설정 열기       오른쪽 위  ...  버튼

  사용법 보기     오른쪽 위  ?  버튼


------------------------------------------------
3. 네 개의 탭
------------------------------------------------

  오늘    오늘 할 일과 오늘 해야 할 반복 루틴
  루틴    최근 4주 달성률과 전체 루틴 목록
  예정    내일 이후에 할 일
  메모    길게 적어 두는 글 (10. 메모 를 보세요)

  Ctrl+1 ~ Ctrl+4 로도 넘길 수 있습니다.


------------------------------------------------
4. 항목 추가하기   (가장 중요)
------------------------------------------------

맨 아래 입력칸에 한 줄로 적고 엔터만 치면 됩니다.
날짜나 시간을 말하듯이 적으면 알아서 알아듣습니다.
적는 동안 초록색 글씨로 미리 보여줍니다.


[ 매일 하는 일 - 하루 지나면 체크가 자동으로 풀립니다 ]

  매일 물 2L 마시기
  평일 아침 회의                 (월~금)
  주말 대청소                    (토, 일)
  월수금 저녁 운동               (월, 수, 금)
  화목 재고 점검                 (화, 목)
  매주 월요일 주간보고

  * 요일 글자를 두 개 이상 붙여 적으면 (월수금, 화목 등)
    자동으로 반복 루틴이 됩니다.

  * '루틴' 탭에서 적으면 "매일" 같은 말을 안 붙여도
    전부 반복 루틴으로 들어갑니다.


[ 한 번만 하는 일 ]

  장부 정리                      (오늘)
  내일 오후 3시 거래처 미팅
  모레 세금 신고
  수요일 팀 회의                 (다음 수요일)
  9/15 정산 마감
  9월 20일 계약 갱신
  25일 결산                      (이번 달 25일)
  14:30 고객 통화                (오늘 2시 반)


[ 중요한 일 표시하기 ]

  문장 맨 뒤에 붙이면 동그라미 색이 바뀝니다.

      !1    가장 중요   (빨강)
      !2    보통        (주황)
      !3    낮음        (파랑)


[ 같이 쓰기 ]

  내일 오후 3시 보고서 제출 !1

  -> 내일 오후 3시 마감, 빨간색으로 표시,
     제목은 "보고서 제출" 로 들어갑니다.


------------------------------------------------
5. 하루가 바뀔 때
------------------------------------------------

기본적으로 새벽 4시에 날짜가 넘어갑니다.
자정이 아니라 새벽 4시인 이유는, 밤 늦게까지
일한 날에 체크가 억울하게 사라지지 않게
하기 위해서입니다.
(설정에서 원하는 시각으로 바꿀 수 있습니다)

날짜가 넘어가면 이렇게 됩니다.

  - 반복 루틴 체크가 전부 풀립니다
  - 날짜가 오늘 날짜로 바뀝니다
  - 못 끝낸 할 일은 오늘로 넘어오고
    "밀림 O일" 이 붙습니다

컴퓨터를 며칠 꺼놨어도, 켜는 순간
그동안의 기록을 한 번에 정리해줍니다.

반복 루틴을 며칠 연속으로 해내면 옆에
불꽃 표시와 함께 며칠째인지 나옵니다.
하루라도 빠뜨리면 다시 처음부터 시작합니다.


------------------------------------------------
6. 설정   (오른쪽 위  ...  버튼)
------------------------------------------------

  하루 시작 시각        날짜가 넘어가는 시각
  미완료 자동 이월      못 끝낸 일을 다음 날로
  항상 위에 표시        다른 창에 안 가려지게
  부팅 시 자동 시작     컴퓨터 켜면 자동 실행
  투명도                마우스를 뗐을 때 흐려지는 정도


------------------------------------------------
7. 적어둔 내용은 어디에 저장되나요
------------------------------------------------

내 컴퓨터에만 저장됩니다.
인터넷으로 아무것도 주고받지 않습니다.

  저장 위치
  Flow.exe 가 있는 폴더 안의 data 폴더

즉 프로그램 옆에 같이 있습니다.
폴더째 복사해두면 그게 백업이고,
다른 컴퓨터로 폴더를 옮기면 적어둔 내용도 따라옵니다.

정확한 경로는 설정(오른쪽 위 ... 버튼) 맨 아래에
표시되니 궁금하면 거기서 확인하세요.


------------------------------------------------
8. 업데이트
------------------------------------------------

새 버전이 나오면 알아서 받아옵니다.
따로 다시 받으실 필요가 없습니다.

앱을 켤 때 한 번 확인하고, 켜 두는 동안에는
30분마다 다시 확인합니다. 받을 것이 없으면
아무것도 띄우지 않습니다.

준비가 되면 입력칸 위에

    새 버전 1.0.1 준비됨      지금 재시작

이런 초록색 줄이 뜹니다. 눌러주시면 됩니다.
급하지 않으면 그냥 두셔도 되고, 다음에 눌러도 됩니다.

원하지 않으시면 설정에서 "자동 업데이트"를 끄면
인터넷을 아예 쓰지 않습니다.


------------------------------------------------
9. 알아두면 좋은 것
------------------------------------------------

  - 컴퓨터에 부담을 거의 주지 않습니다.
    가만히 있을 때 CPU 0%, 메모리 약 50MB
    (참고로 크롬은 보통 1000MB 넘게 씁니다)

  - 시각을 적으면 그때 알려줍니다.
    "내일 오후 3시 회의" 처럼 시각을 적으면
    그 시각에 해당 줄이 물들고 처리할 때까지
    남아 있습니다. 창이 보이는 동안에는
    소리가 나지 않습니다.

    창을 트레이에 숨겨 둔 동안에만
    Windows 알림으로 한 번 알려줍니다.
    설정 > 하루 에서 끌 수 있습니다.

    게임이나 발표 중, 집중 지원이 켜져 있으면
    방해하지 않습니다. 그래도 물든 줄은
    남아 있어서 나중에 보면 그대로 있습니다.

  - 여러 PC에서 같은 내용을 쓸 수 있습니다.
    설정 > 데이터 저장 위치 > 폴더 바꾸기 에서
    구글 드라이브나 OneDrive 폴더를 고르면 됩니다.
    두 번째 PC에서도 같은 폴더를 고르기만 하면
    그 내용을 그대로 이어받습니다.

    안 쓰셔도 됩니다. 아무것도 안 건드리면
    지금처럼 이 PC 안에서만 돌아갑니다.

    창 위치와 크기, 알림이 울렸다는 표시는
    PC마다 따로입니다. 그래서 각 PC에서 다 울립니다.

    메모도 같은 폴더에 들어 있어 같이 따라갑니다.
    (10. 메모 를 보세요)

  - 오늘 예정이 아닌 요일의 루틴은 '루틴' 탭에서
    동그라미 대신 점으로 표시되고 체크할 수 없습니다.
    (연속 기록이 어긋나지 않게 하기 위해서입니다)

  - 처음 실행하면 예시 루틴 3개가 들어있습니다.
    필요 없으면 지우고 쓰시면 됩니다.

------------------------------------------------
10. 메모
------------------------------------------------

업무 절차나 체크 목록처럼 한 줄로는 모자란 글을
적어 두는 곳입니다. 메모 탭에서 씁니다.

[ 새 메모 ]

  메모 탭 맨 아래 입력칸에 적고 엔터.
  적은 글이 제목이 되고, 메모 창이 열립니다.
  첫 줄(비어 있지 않은 첫 줄)이 언제나 제목입니다.

[ 메모 창 ]

  메모 탭에서 메모를 누르면 메모 창이 열립니다.
  왼쪽은 메모 목록, 오른쪽은 본문입니다.

  읽기 모드    서식이 정리되어 보이고 체크 칸을
               바로 누를 수 있습니다. 처음에는 이쪽입니다.
  쓰기 모드    본문을 누르거나 Ctrl+E.
               적은 글 그대로 보입니다.
               Esc 또는 Ctrl+E 로 읽기 모드로 돌아갑니다.

  저장 버튼은 없습니다. 입력이 1초 멈추면 저장하고,
  다른 메모로 옮기거나 창을 닫을 때도 저장합니다.
  저장하지 못한 글이 남아 있으면 창이 닫히지 않습니다.

  창 모양은 위젯과 같습니다. 맨 위 줄을 끌어 옮기고,
  두 번 누르면 화면 가득(다시 누르면 원래대로) 됩니다.
  가장자리나 모서리를 끌면 크기가 바뀝니다.
  오른쪽 위  —  최소화,  □  화면 가득,  ✕  닫기.

  메모 창 오른쪽 위 ? 버튼에 간단한 사용법이 있습니다.

[ 서식 단추 ]

  본문 위에  큰 소제목 · 소제목 · 번호 · 점 · 체크
  단추가 있습니다. 기호를 몰라도 서식을 넣을 수 있습니다.

  쓰기 모드    커서가 있는 줄(여러 줄을 골랐으면 그 줄들)
               앞에 기호를 붙입니다. 이미 그 기호면 뗍니다.
               다른 기호가 있으면 이 기호로 바꿉니다.
               번호는 위 번호에 이어서 매깁니다.
  읽기 모드    쓰기 모드로 바뀌고, 본문 맨 끝에 그 기호로
               시작하는 새 줄이 생깁니다. 바로 적으면 됩니다.

[ 엔터로 목록 이어 쓰기 ]

  쓰기 모드에서 체크 · 번호 · 점 줄 끝에서 엔터를 치면
  다음 줄에 같은 기호가 붙습니다(번호는 다음 번호,
  체크는 빈 칸, 들여쓰기도 그대로).
  기호만 있고 글이 없는 줄에서 엔터를 치면 기호가
  지워지고 목록이 끝납니다.
  기호 없이 줄만 바꾸려면 Shift+엔터.

[ 가벼운 서식 ]

  줄 단위로만 알아봅니다. 줄 안의 꾸밈(굵게 등)은 없습니다.

  적은 것                   보이는 것
  ------------------------  ------------------------
  # 글  /  ## 글            소제목 (큰 / 조금 큰)
  1. 글                     번호 단계
  - 글  /  * 글             점 목록
  [ ] 글  /  - [ ] 글       빈 체크 칸
  [x] 글  /  - [x] 글       체크된 칸 (글은 흐리게)
  빈 줄                     문단 사이
  그 밖                     보통 글

  체크 칸을 누르면 그 줄의 [ ] 와 [x] 만 바뀌어 저장됩니다.

[ 태그 · 검색 · 고정 ]

  - 글 어디에든 #정산 처럼 # 바로 뒤에 글자를 붙이면
    태그가 됩니다. "# 준비" 처럼 띄우면 태그가 아니라
    소제목입니다.
  - 태그는 제목 아래 태그 칸에 칩으로 모여 보입니다.
    읽기 · 쓰기 모드 모두 보입니다.
  - 태그 칸의 "+ 태그 추가" 에 이름을 적고 엔터를 치면
    본문을 고치지 않고 태그가 붙습니다. 적는 동안
    이미 쓰는 태그가 아래에 떠서 눌러 고를 수 있습니다.
    띄어쓰기 · # · 쉼표는 태그 이름에 쓸 수 없습니다.
  - 이렇게 붙인 태그는 칩의 ✕ 로 뗍니다.
    본문에 #태그 로 적은 것은 흐린 칩으로 보이고
    ✕ 가 없습니다. 본문에서 지우면 사라집니다.
  - 메모 탭의 태그 칩을 누르면 그 태그만 보이고,
    다시 누르면 풀립니다.
  - 검색칸은 제목과 본문에서 찾습니다.
    #태그 를 치면 그 태그로 거릅니다.
  - 메모 창 위의 📌 를 누르면 고정됩니다.
    고정한 메모가 목록 맨 위에 옵니다.
    나머지는 최근에 고친 순입니다.

[ 할 일 · 루틴과 연결 ]

  위젯에서 할 일이나 루틴을 오른쪽 클릭 → 메모 연결.
    새 메모 만들기    그 제목으로 메모를 만들어 연결
    메모 제목         이미 있는 메모에 연결
    연결 끊기         이 항목의 연결만 끊기(메모는 그대로)
  연결되면 줄 오른쪽에 📝 가 생기고, 누르면 그 메모가
  바로 열립니다. 여러 항목이 같은 메모를 가리켜도 됩니다.
  메모 창 태그 칸 아래에 "연결: 루틴 · AK넷 배포" 처럼
  이 메모를 가리키는 항목이 보입니다.
  메모를 휴지통에 보내면 📝 만 숨습니다. 되살리면 다시 보입니다.

[ 매일 하는 절차 — 매일 초기화 · 모두 풀기 ]

  메모 창 위 📌 옆의 ↻ 를 켜 두면, 하루가 바뀔 때
  (하루 시작 시각, 기본 새벽 4시) 체크가 [ ] 로 풀립니다.
  켠 날에는 풀리지 않고 다음 날부터 풀립니다.
  ↻ 가 켜진 메모는 목록에도 ↻ 가 붙습니다.
  지금 바로 다 풀고 싶으면 "모두 풀기"
  (체크된 칸이 있을 때만 누를 수 있습니다).
  쓰던 글은 먼저 저장한 뒤 풉니다.

[ 어디에 저장되나요 ]

  데이터 폴더 안 memos 폴더에, 메모 하나가
  .md 파일 하나로 저장됩니다. 메모장으로도 열립니다.
  파일 이름은 제목에서 만들어지고(#태그 낱말은 뺍니다),
  제목을 바꾸면 파일 이름도 바뀝니다.
  메모를 하나도 안 만들었으면 memos 폴더도 없습니다.

  메모 맨 위의 --- 로 둘러싸인 부분은 Flow 가
  쓰는 표시(고정 · 태그 칸의 태그 등)입니다. 지우지 마세요.
  메모장으로 만든 .md / .txt 파일을 memos 폴더에
  넣어도 메모로 보입니다.

  데이터 폴더가 구글 드라이브나 OneDrive 면
  메모도 같이 따라갑니다.

  메모 창 위에 노란 띠로 알려 줍니다. 글은 사라지지 않으니
  두 글을 보고 직접 합치면 됩니다.
  드라이브가 같은 메모의 복사본을 만든 경우에는
  "제목 (충돌 사본)" 이 생깁니다.

[ 휴대폰에서 ]

  휴대폰 Flow 화면 위의 "오늘 | 메모" 에서 메모 를 누르면
  PC 의 메모가 보입니다(휴지통에 있는 것은 빼고).
  - 검색칸 · 태그 칩 · 📌 고정 · ↻ 는 PC 메모 탭과 같습니다.
  - 메모를 누르면 전체 화면으로 열립니다. 맨 위 "‹" 단추로
    연 곳(메모 목록이면 "‹ 메모", 오늘 화면의 📝 면 "‹ 오늘")으로
    돌아갑니다.
  - 체크 칸을 누르면 바로 바뀌고 "PC 반영 대기" 가 붙습니다.
    PC 가 켜져 있으면 1분 안에 PC 메모에도 체크가 들어갑니다.
    PC에서 그 메모를 쓰는 중이면(쓰기 모드) 쓰기를 마치면(Esc)
    들어갑니다. 그동안 휴대폰에는 "PC에서 쓰는 중 · 쓰기를 마치면
    들어갑니다", PC 메모 창에는 "휴대폰 체크 n개가 기다립니다" 가
    보입니다.
    그 사이 PC 에서 줄이 지워졌으면 그 체크는 건너뜁니다.
  - 오늘 화면의 할 일 · 루틴에 📝 가 있으면 누르면 그 메모가
    열립니다(줄은 체크되지 않습니다).
  - PC 가 꺼진 채 하루가 지났으면 ↻ 메모는 체크를 풀어
    보여 줍니다. PC 가 켜지면 그대로 맞춰집니다.
